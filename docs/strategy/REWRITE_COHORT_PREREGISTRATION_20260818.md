# 리라이팅 코호트 사전 등록 (2026-08-18 작성)

> 작성 시점에 12건 중 landed는 0건이고 창은 하나도 닫히지 않았다.
> **결과를 보기 전에 기준을 고정하기 위한 문서다.** 8월 31일 이후 이 파일의 기준을 바꾸지 않는다.

## 1. 배경

`2026-08-18_preregistered_w5_verdict.md`에서 W5 13건이 0/13으로 판정됐고 원인 조사를 재개했다.
그런데 원인 후보(소재 / TOP20 고착)를 가를 실험은 이미 돌고 있다.
2026-08-06~08-17에 발행한 180~191번 12건은 전부 과거 발행 소재를 새 글로 다시 쓴 것이다.
직접 원본은 022·024·028·029·038·040·047·059·070·088·012/089·023/092로 서로 다르며,
`과거 소재 재작성`이라는 공통 처치군이지 내용이 동일한 단일 처치는 아니다.

## 2. 모수

| 항목 | 값 |
| --- | --- |
| 모수 | 원고 글번호 180~191, **12건** |
| 처치 | 과거 발행 소재를 새 글로 다시 구성해 발행 |
| 발행 구간 | 2026-08-06 ~ 2026-08-17 |
| 최종 창 마감 | **2026-08-31** (191번 D14) |
| 제외 | 192번 (작성 시점 미발행). 발행돼도 이 코호트에 넣지 않는다. |

192번 이후를 사후에 모수에 추가하지 않는다. 분모를 결과를 본 뒤 늘리는 것은 기준 변경이다.

2026-08-18 등록부 대조에서 180~191은 모두 `발행완료·URL등록완료`이며, 성과 원장의
`published_at`은 2026-08-06부터 2026-08-17까지 하루씩 이어진다.

## 3. 판정 방법

- `verdict` 필드를 읽지 않는다. 수집기는 D14 전에도 `faded`를 찍는다.
- 각 글의 `observation.day`가 3~14인 TOP20 등장 횟수를 직접 센다.
- **landed = 창 안 등장 2회 이상.**
- 관측 유효일은 D3~D14에 TOP20 10행 이상이 확보된 날로 센다.
- 관측 유효일이 3일 미만인 글이 하나라도 있으면 분모에서 빼지 않고 **12건 전체 판정을 보류**한다. 누락 daily를 백필한 뒤 다시 계산한다.
- 이 3일 규칙은 수집기의 기존 판정 분기와 동일하지 않다. 수집기는 `observedDays >= 5`일 때만 `coverageValidDays < 3` 검사를 실행하므로, 과거 판정 원장의 `landed`·`faded` 적격 분모는 최소 5일 분기까지 통과한 글이다.

기존 성과 판정의 적격 상태(`landed`·`faded`)만 쓰면 W1~W4는 109건/39건이며, 044번은

과거 구간에 적용한 참고값이고, 과거 판정 기록을 소급 변경하지 않는다.

## 5. 사전 등록 기준 (12건 기준)

| landed | 판정 | 근거 |
| ---: | --- | --- |
| **3건 이상** | **회복.** 리라이팅 계속한다. | 실제 성공률이 W5 수준(5%)이었다면 3건 이상 나올 확률 약 2% |
| **2건** | **보류.** 다음 코호트로 확장 판정. | 어느 쪽으로도 유의하지 않다 |
| **0~1건** | **회복 실패.** 소재 처치로 설명되지 않는다. | 실제 성공률이 27.5%였다면 1건 이하일 확률 약 12% |

`0~1건`이 나와도 "리라이팅이 나쁘다"는 뜻이 아니다. **"소재를 바꾸는 것만으로는 진입이 회복되지 않는다"**는 뜻이고, 그때 조사 대상은 소재에서 유통·경쟁 환경으로 옮긴다.
위 확률은 사전 등록한 운영 판정 기준이다. 특히 27.5% 기저에서 1건 이하가 나올 확률 11.7%는 통상 5% 유의수준의 통계적 확정이 아니다.

## 6. 교란 통제 — TOP20 고착 지표

소재 효과와 환경 회복을 분리하기 위해 같은 기간의 고착 지표를 함께 기록한다.

나이는 발행일을 D0으로 두고 `관측일 - 발행일`로 계산한다. 일별 TOP20 중앙 나이는 20행을
나이순으로 정렬한 **11번째 값(위쪽 중앙값)**이며, 7일 값은 이 일별 값의 산술평균이다.
최연소 나이는 일별 최솟값이고, 7일 값은 일별 최솟값 7개의 중앙값이다.

작성 시점(데이터 기준일 2026-08-11~08-17 7일) 기준값:

| 지표 | 값 |
| --- | --- |
| TOP20 위쪽 중앙 나이 평균 | **58.57일** |
| TOP20 최연소 나이 중앙값 | **10일** |
| 비교: 2026-07-20 중앙 나이 | 21일 |

2026-08-31 판정 시 같은 방식으로 8/25~08/31 7일 값을 계산해 아래 표로 읽는다.

| | 고착 지속 (중앙 나이 50일 이상 유지) | 고착 완화 (중앙 나이 40일 미만으로 하락) |
| --- | --- | --- |
| **landed 3건 이상** | 리라이팅 유효 신호. 계속하되 다음 코호트에서 반복 확인. | **분리 불가.** 환경 회복 때문일 수 있다. 다음 코호트에서 재검정. |
| **landed 0~1건** | 자리 부족 가설 지지. 조사를 유통·경쟁 쪽으로 이동. | 고착 완화와 소재 재사용만으로 설명되지 않는다. 원고 품질·형식으로 조사 이동. |

이 표를 판정 뒤에 고쳐 쓰지 않는다.
landed 2건이거나 중앙 나이 평균이 40일 이상 50일 미만이면 이 교란표로 방향을 정하지 않고 보류한다.
이 표는 시간대·경쟁·제목·발행 리듬을 모두 통제한 무작위 실험이 아니므로 원인을 확정하지 않는다.
