# 리뷰릴스 기반 네이버 클립·블로그 포스팅 워크플로

> 목적: `C:\Users\hjh\안티그래비티\문장군 컨텐츠`에서 승인 완료된 네이버 고객 리뷰 숏폼을 네이버 클립과 블로그 포스팅으로 안전하게 확장한다.

## 원본과 저장 경계

- 원본 프로젝트: `C:\Users\hjh\안티그래비티\문장군 컨텐츠`
- 사용할 수 있는 근거: 승인된 리뷰 원문 범위, 최종 대본, 최종 숏폼 MP4, QA 완료 메타데이터
- 블로그 저장소에 남길 수 있는 것: 비식별 소재 요약, 콘텐츠 ID, 블로그 원고, 공개된 네이버 URL
- 복사·커밋 금지: 고객 리뷰 캡처, 고객 사진, 원본 영상, 음성, MP4, 실명·주소·연락처 등 개인정보

## 작성 순서

1. `문장군 컨텐츠/AGENTS.md`와 해당 리뷰 패키지의 승인·QA 상태를 확인한다.
2. 리뷰 원문에서 실제로 확인되는 사건, 불편, 선택 이유, 고객 반응을 분리한다.
3. 기존 `POSTING_REGISTRY`에서 같은 고객 문제와 핵심 키워드의 중복·카니발 여부를 확인한다.
4. 클립은 사건과 반전을 짧게 보여주고, 블로그는 `문제 제기 → 고객 상황 → 선택 기준 → 해결 → 우리 집 확인 항목`으로 확장한다.
5. 직접 인용은 원문과 일치할 때만 사용한다. 원문에 없는 감정, 효과, 수치, 일정, 비용은 실제 경험처럼 쓰지 않는다.
6. 원고는 기존 단일 파일 표준과 발행 하드게이트를 그대로 통과해야 한다.
7. 네이버 발행 후 블로그 URL과 클립 연결 상태를 `POSTING_REGISTRY.json`의 리뷰릴스 섹션에 등록하고 `npm run render:strategy`를 실행한다.

## 콘텐츠 ID와 파일명

- 원본 콘텐츠 ID는 `리뷰릴스-NNN`으로 기록한다. 예: `리뷰릴스-005`.
- 블로그 원고 파일은 기존 숫자 원고와 충돌하지 않도록 `posts/리뷰릴스_NNN_핵심소재.md` 형식을 쓴다.
- 같은 리뷰를 재활용한 클립·블로그·후속 콘텐츠는 동일한 콘텐츠 ID 아래에서 관리한다.

## 발행 판단

- 영상이 완성됐다는 이유만으로 블로그 글을 자동 발행하지 않는다.
- 검색 키워드와 고객 문제 연결이 약하면 클립만 활용하고 블로그 확장은 보류할 수 있다.
- 기존 보호글이나 최근 발행글과 가까우면 새 정보글로 위장하지 않고 리뷰 사례형 각도로 분리한다.
- 네이버 클립의 조회수만으로 성공을 판단하지 않는다. 블로그 유입어, 게시글 반응, 클립 유지율·완주율을 함께 본다.
